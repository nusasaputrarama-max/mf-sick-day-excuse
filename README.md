A [make.fun](https://make.fun/bounty/u-zeroxfive-the-funniest-sick-day-excuse-37423a36) program/v1 entry for **The Funniest Sick-Day Excuse** ($2).

`main.ts` (Node 22) writes one funny sick-day excuse line, under 200 characters,
to `/output/entry.txt` — nothing else:

> Sorry, can't come in today — my robot vacuum escaped overnight and I've spent all morning negotiating its return with the neighbours. It's winning.

## Run

```sh
node main.ts   # Node 22.18+
```

The output is deterministic: two runs produce byte-identical `/output/entry.txt`.
